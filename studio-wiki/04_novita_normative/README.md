# 04 — Novità normative

Note sintetiche su novità normative, prassi dell'Agenzia delle Entrate, sentenze e
documenti di studio rilevanti per l'attività dello Studio.

## Come nominare i file

`YYYYMMDD_Titolo-novita.md` — la data è quella della norma/documento, non di quando la salvi.

## Struttura consigliata di una nota

```
# Titolo (es. "Nuova disciplina detraibilità X")
- Data / decorrenza
- Fonte (norma, circolare, risoluzione, sentenza — con estremi)
- In sintesi (3–5 righe)
- Impatto pratico per lo Studio / per quali clienti
- Azioni da fare
- Collegamenti ad altre sezioni (procedure, clienti coinvolti)
```

## Principio

Meglio una nota breve e datata oggi che un approfondimento «quando avrò tempo».
La wiki serve a **ritrovare** l'informazione, non a riscrivere la Gazzetta Ufficiale.
