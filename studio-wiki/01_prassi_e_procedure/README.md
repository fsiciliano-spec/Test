# 01 — Prassi e procedure

Procedure interne e checklist ricorrenti dello Studio. Sono i «come si fa da noi».

## Cosa mettere qui

- Procedura controllo IVA mensile/trimestrale
- Checklist visto di conformità (IVA, 730, ecc.)
- Iter attività collegio sindacale (verifiche periodiche, relazioni)
- Iter attività OdV 231 (flussi informativi, riunioni, aggiornamento MOG)
- Procedure di revisione contabile
- Onboarding nuovo cliente

## Come nominare i file

`YYYYMMDD_Procedura-controllo-iva-mensile.md`

## Struttura consigliata di una procedura

```
# Titolo procedura
- Ambito / quando si applica
- Documenti necessari (input)
- Passi operativi (numerati)
- Controlli / punti critici
- Output atteso
- Riferimenti normativi e fonti
- Ultima revisione: YYYY-MM-DD
```
