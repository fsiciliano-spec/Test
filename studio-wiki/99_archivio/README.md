# 99 — Archivio

Contenuti superati (procedure sostituite, note su norme abrogate, modelli vecchi)
che si conservano per storicità e tracciabilità, ma che non vanno più usati come
riferimento corrente.

## Regola

Non cancellare: **spostare** qui. In uno studio professionale la tracciabilità di
«cosa valeva prima» è utile (revisione, contenzioso, 231).

Indicare in testa a ogni file archiviato: **data di archiviazione** e **cosa lo sostituisce**.
