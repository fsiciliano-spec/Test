# 06 — Decisioni e note

Il «registro della memoria» dello Studio: decisioni prese, chiarimenti, e soprattutto
le **correzioni ricorrenti** che, una volta annotate, diventano regole per gli output futuri.

## Perché è la sezione più importante

Ogni volta che correggi un output dell'assistente, quella correzione va scritta qui.
Così non la ripeti più: la wiki «impara» dallo Studio.

## Come nominare i file

Può bastare un file cumulativo per anno: `decisioni_2026.md`, con voci datate in cima.

## Struttura di una voce

```
## YYYY-MM-DD — Titolo breve
- Contesto: (cliente / attività / progetto interno)
- Decisione / regola: (cosa vale d'ora in poi)
- Motivazione / fonte: (se rilevante)
```

## Esempi di voci tipiche

- «Nei verbali del collegio sindacale usare sempre l'intestazione X e la formula Y.»
- «Per il cliente Z l'IVA sulle spese di rappresentanza va trattata così…»
- «Nelle comunicazioni ai clienti chiudere con la firma dello Studio, non generica.»
