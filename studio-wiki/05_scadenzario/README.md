# 05 — Scadenzario

Scadenze ricorrenti dello Studio e, se utile, un riepilogo trasversale di quelle dei clienti.

## Cosa mettere qui

- Scadenzario fiscale ricorrente (liquidazioni IVA, LIPE, F24, dichiarativi, CU, 770…)
- Scadenze degli incarichi societari (relazioni collegio sindacale, riunioni OdV 231)
- Adempimenti periodici dello Studio (antiriciclaggio, formazione, ecc.)

## Formato consigliato

Una tabella per periodo/mese:

```
## Mensili
| Giorno | Adempimento | Note |
|---|---|---|
| 16 | Versamento IVA mensile / ritenute | F24 |
| ...| ... | ... |

## Annuali
| Data | Adempimento | Note |
|---|---|---|
```

> Le scadenze **specifiche di un cliente** stanno in `03_clienti/<Cliente>/scadenze.md`.
> Qui si tiene la vista d'insieme.
