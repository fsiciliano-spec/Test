# 02 — Modelli e format

Modelli di documenti riutilizzabili, da cui l'assistente parte per produrre gli output.

## Cosa mettere qui

- Verbali: CdA, collegio sindacale, OdV 231, assemblea
- Comunicazioni ai clienti: richiesta documenti, sollecito CU mancanti, invio scadenze
- Report: controllo IVA, monitoraggio bilancio, riconciliazione ritenute/CU
- Lettere e relazioni ricorrenti

## Come nominare i file

`YYYYMMDD_Modello-verbale-collegio-sindacale.md`

## Nota

Molti format sono già coperti da skill dedicate (es. verbali riunione, report IVA,
monitoraggio bilancio, riconciliazione CU). Qui si tengono le **varianti di studio**:
intestazioni, formule ricorrenti, clausole tipo, stile che l'assistente deve rispettare.

Ogni modello dovrebbe indicare in testa: **quando si usa** e **quali campi vanno compilati**.
